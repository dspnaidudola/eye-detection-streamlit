# Haar Cascade Eye Detection

## Project Description

This project detects human eyes using the OpenCV Haar Cascade
pre-trained classifier.

No deep-learning model is trained.

## Features

- Upload an image
- Detect face internally
- Detect eyes
- Draw only eye bounding boxes
- Display number of detected eyes
- Real-time webcam eye detection
- Streamlit web interface

## Technologies

- Python
- OpenCV
- Streamlit
- Streamlit-WebRTC
- NumPy
- Pillow
- Haar Cascade
